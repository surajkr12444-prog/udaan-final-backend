# Udaan Backend v5 — Chatbot

- Improved `/api/assistant/chat` so it is useful even without a Gemini API key.
- Supports Hindi, Hinglish and English language detection.
- Provides Udaan website usage guidance, documents, eligibility, EMI, business loan and scholarship help.
- Recognizes seeded scheme/scholarship names and uses their real stored descriptions/documents/benefits.
- Keeps official-portal guide mode and step-by-step application guidance.
- Gemini remains optional via `GEMINI_API_KEY`.
